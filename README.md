# Estrategia Empresarial & Innovación

Colección de presentaciones magistrales en español diseñadas para cursos de licenciatura, maestría y posgrado en la **Universidad Anáhuac Mayab**, impartidas y desarrolladas por el **Prof. J. Christopher Westland**.

Todas las diapositivas cuentan con diseño corporativo institucional, tipografía moderna, paleta cromática Anáhuac (naranja institucional `#FF5900`, antracita `#231F20` y tonos piedra cálidos), diagramas vectoriales nativos y notas de orador integradas.

## 🎯 Instrucciones de Uso
1. Para visualizar o presentar, descargue directamente cualquiera de los archivos `.pptx`.
2. Las presentaciones son totalmente compatibles con Microsoft PowerPoint 2016+, Office 365, Google Slides y Apple Keynote.
3. Se recomienda tener instaladas las fuentes tipográficas del sistema **Segoe UI** o **Arial** para la mejor fidelidad visual.
